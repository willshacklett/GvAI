# GV Sample Validation Data

This folder contains tracked sample datasets for GV validation experiments.

Purpose:

- provide reproducible examples
- demonstrate expected CSV structure
- allow validation harness testing without external/private datasets

Current datasets:

- sample_service_latency.csv

Columns:

- time
- value
- event

Example event labels:

- normal
- disturbance
- recovery
- recovered
- incident
- failure
- collapse
