# GV Candidate Window Review Protocol

Purpose:

Separate:
- detector output
from
- human interpretation.

Rules:

1. GV generates candidate windows only.
2. Humans review candidate windows independently.
3. Human reviewers should not modify GV scores.
4. Reviewers should document:
   - operational stress
   - recovery failure
   - normalization success/failure
   - possible false positives
5. Candidate windows are not proof.

Goal:

Determine whether recoverability degradation repeatedly appears
inside candidate stress windows more often than chance.
