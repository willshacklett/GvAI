# GV Intelligence Continuity Scorecard

## Purpose

Define the continuity dimensions intelligence may depend on.

## Scorecard

| Dimension | Risk If Lost | GV Question |
|---|---|---|
| memory continuity | identity fragmentation | Can the system preserve useful history without hallucinating continuity? |
| intent continuity | goal drift | Can the system adapt while preserving the core task? |
| correction continuity | repeated failure | Can the system recover from error instead of reinforcing it? |
| constraint continuity | unsafe optimization | Can the system preserve boundaries under pressure? |
| global coherence | local wins with global collapse | Can local adaptation remain globally consistent? |
| truth continuity | narrative bias | Can the system preserve failed evidence as constraint? |

## Foundation

> Intelligence requires recoverable continuity through change.

## Current Interpretation

Prediction alone is not enough.

Intelligence must preserve memory, correction, constraint, intent, and global coherence.

## Next Build Target

Create an intelligence drift/recovery harness that tests whether an agent can preserve continuity under perturbation.
