# GV Base Code Manifest + Kernel

## Base Code

> Preserve recoverable future access through change.

GV is the continuity rule beneath the system.

A system is GV-aligned when it can change, adapt, explore, and improve without destroying recoverable future access.

A system is GV-broken when it trades recoverable futures for short-term gain, rigid control, destructive drift, hidden corruption, or irreversible collapse.

## Core Principle

GV does not mean never change.

GV means:

> Change without losing the ability to recover, adapt, reconnect, and continue.

## Operating Test

Before any meaningful action, ask:

> Does this preserve or reduce recoverable future access?

## Kernel

GV = preserve(recoverable_future_access) through(change)

## Output Objective

Maximize continuity-weighted survivability.
