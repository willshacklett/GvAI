# GV Core Intuition

## Do not lose the foundation

GV begins with a simple intuition:

Persistent existence requires continuity.

Continuity is not merely a tuned score.

Continuity is the preserved relation that lets a system remain itself through change.

## Core claim being tested

If a system persists, then some recoverability/order structure must survive:

- disturbance
- transformation
- noise
- scale changes
- partial observability
- local/global decoupling

## What GV is not

GV is not just:

- a fitted scalar
- PCA
- a tuned coefficient
- a projection trick
- a narrative rescue layer

## What GV is being tested as now

GV is being tested as a foundational continuity-order relation.

A state has stronger GV when it preserves more recoverability continuity relations than another state.

## Why order matters

Weights can be tuned.

But order survival is harder to fake.

If continuity is foundational, it should survive as relational structure even when numeric coordinates shift.

## Scientific rule

The core intuition stays.

The tests get harder.

If the order breaks, document where it breaks.

If it survives, build from the invariant upward.
