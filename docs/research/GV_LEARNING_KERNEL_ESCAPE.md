# GV Learning Kernel Escape

## Purpose

Let GV learn.

The prior OVEC benchmark showed:

- strict viability preserved itself into irrelevance
- antifragile escape won narrowly
- GV controlled escape preserved much stronger truth/constraint/coherence

The next question is:

Can GV learn when kernel escape is worth the risk?

## Strong GV evolution

GV is not a fixed rule.

GV is a recoverability-learning system.

## Core hypothesis

Universal survivability may require adaptive risk calibration:

- escape when novelty opportunity is high
- constrain when recoverability is degrading
- learn from failed escapes
- learn from successful basin discoveries
- preserve truth/constraint/coherence as the recovery spine

## Kill condition

GV weakens if a learning escape policy cannot outperform fixed antifragile escape
over repeated regimes.

## Win condition

GV strengthens if learning escape matches or beats antifragile novelty
while preserving stronger truth, constraint, coherence, and recoverability.
