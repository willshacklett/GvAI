# GV Order-Invariant Continuity

## Purpose

Stop treating GV as a tunable weighted scalar.

This test removes the "a tuning" problem.

## Core correction

A foundational GV should not depend on tuned weights.

Instead, GV should preserve continuity relationships:

- which states are more recoverable
- which states are degrading
- which states remain coherent
- which states lose continuity

## New object

GV is tested as an order/topology condition:

Continuity is preserved if pairwise recoverability order survives representation changes.

## Why this matters

Weighted scalar formulas can be arbitrary.

Order invariants are harder to fake.

If GV is foundational, it should appear as a preserved ordering,
not merely a fitted projection.

## Win condition

GV survives if pairwise continuity order remains stable across:

- scale changes
- monotonic transformations
- noise
- coordinate rotations

without tuning weights.

## Loss condition

GV fails if continuity ordering flips under harmless transformations.

## Scientific posture

This does not prove GV.

It tests whether GV behaves like an invariant continuity relation
instead of a tunable score.
