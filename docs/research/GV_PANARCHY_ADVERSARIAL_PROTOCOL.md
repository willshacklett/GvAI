# GV Panarchy Adversarial Protocol

## Purpose

Test whether GV survives multi-scale systems where local recoverability and global recoverability decouple.

## Hostile hypothesis

GV may align with local recoverability while failing as a global scalar.

## Adversarial regimes

- local antifragility
- global degradation
- cyclic/non-monotonic recovery
- persistence without improvement
- local recovery with global hysteresis
- scale-coupled failure

## Win condition

GV survives only if:

- local GV remains coherent
- global GV remains coherent
- PC1 remains dominant across local + global metrics
- no scale-specific rescue weights are required

## Loss condition

GV loses the universal scalar claim if:

- local modules score high while global system degrades
- PC2/PC3 emerge as independent recovery dimensions
- antifragile upward jumps break the fixed 0–1 contract
- scale-specific rescue logic becomes necessary

## Scientific posture

This test is designed to break GV.

Best break wins.
