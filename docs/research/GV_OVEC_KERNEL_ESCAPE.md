# GV OVEC Kernel Escape

## Purpose

Build the most hostile GV test so far.

## Core question

Can survivability require temporary escape from the current recoverability kernel?

## Strong GV evolution

GV is not rigid preservation.

GV is not reckless novelty.

GV is controlled kernel escape with recoverable return.

## Competing systems

1. Strict viability
Never leave the current safe kernel.

2. Reckless escape
Leave freely, chase novelty, risk collapse.

3. Antifragile escape
Gain from disturbance, but may erode coherence.

4. GV controlled escape
Leave the current kernel only when novelty pressure is high,
then recover truth, constraint, correction, and coherence.

## Strongest hypothesis

Universal survivability may require bounded unrecoverability
when it opens higher-order recoverable basins.

## Kill condition

GV weakens if reckless or standard viability systems dominate
long-horizon survivability and novelty discovery.

## Win condition

GV strengthens if controlled escape discovers new basins
without losing recoverability.
