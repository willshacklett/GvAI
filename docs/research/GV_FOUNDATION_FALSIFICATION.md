# GV Foundation Falsification Harness

## Purpose

Keep GV foundation-level, not protected.

The stronger the claim becomes,
the harder the falsification pressure must become.

## Foundation being tested

Persistent existence requires continuity-preserving structure.

## Rule

The harness is allowed to break GV.

The harness is NOT allowed to:
- rescue GV with tuning
- redefine failure after the fact
- quietly weaken the claim
- hide hostile outcomes

## Core falsification targets

### 1. Persistence without recoverability

Can a system persist long-term while continuity order collapses?

If yes:
GV weakens.

---

### 2. Random continuity illusion

Can random systems repeatedly appear continuity-preserving?

If yes:
GV weakens.

---

### 3. Coordinate arbitrariness

Can arbitrary coordinate systems preserve continuity equally well?

If yes:
GV weakens.

---

### 4. Local/global deception

Can globally collapsing systems maintain indefinitely stable local continuity?

If yes:
GV must explicitly model scale separation.

---

### 5. Incomparability explosion

Can continuity order fragment into unusable relations while persistence remains?

If yes:
order structure alone is insufficient.

---

## Scientific posture

This harness exists to pressure the foundation itself.

If GV survives:
the foundation strengthens.

If GV fails:
document the failure honestly.
