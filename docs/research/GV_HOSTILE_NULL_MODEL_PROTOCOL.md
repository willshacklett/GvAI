# GV Hostile Null-Model Isolation Protocol

## Purpose

Give GV a fair chance without protecting it.

This test asks whether GV behaves like a real continuity constraint
or merely like one of many arbitrary projections on compressible data.

## Core position

GV is allowed to be novel.

GV is not allowed to hide from null models.

## Test principle

If GV is foundational, it should survive hostile comparison against:

- random projections
- shuffled labels
- rotated feature spaces
- injected orthogonal noise
- baseline scalar projections

## What survives?

GV survives only if it remains meaningfully aligned with continuity outcomes
better than random or arbitrary projections.

## What fails?

GV weakens if random projections perform equally well.

## Scientific posture

This test does not prove God.

This test does not disprove God.

This test asks whether GV has mathematical privilege
as a continuity constraint under adversarial numerical isolation.\n
