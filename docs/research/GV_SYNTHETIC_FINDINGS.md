# God Variable Synthetic Findings — Current State

## Claim status

This is not proof of a new physical law.

This is a falsifiable recoverability-detection framework with synthetic boundary results.

## Core operational claim

GV behaves as a recoverability-loss detector, not a generic collapse predictor.

## Current equation direction

Gv ≈ f(dR/dt, recovery_time, persistent_degradation_probability)

## Major findings

- GV is not a volatility detector.
- GV is not a magic predictor.
- GV detects critical slowing when recovery force weakens before visible collapse.
- Alpha-space has a stable discriminating region around 0.75–0.85.
- GV appears precursor-strength limited, not primarily noise-limited.

## Honest limitations

- Synthetic systems are still controlled.
- Real-world validation is early.
- The framework needs external datasets.
- Current GV does not detect weak precursors below the observed boundary.
- Current GV does not detect abrupt collapse without prior degradation.
- Alpha is not yet mechanistically derived from first principles.

## Research posture

Do not tune GV to pass.

Map where it works, where it fails, and what mechanisms define the boundary.
