# GV Dominant Recoverability Axis Hypothesis

## Purpose

This reframes the universal scalar claim into a harder, cleaner test.

## Strong hostile critique

Recoverability may not be one-dimensional.

A single scalar may lose information.

Therefore, GV should not merely claim:

GV is universal.

The stronger scientific test is:

GV captures a dominant recoverability axis across domains.

## Hypothesis

GV is useful if it behaves like the first dominant recoverability component across systems.

That means GV may not explain every recovery behavior.

But it should preserve the main ordering:

- stable recoverable systems high
- transient stress above persistent degradation
- persistent degradation below recoverable stress
- irrecoverable failure lowest

## Falsification

GV fails this hypothesis if:

- recoverability requires multiple independent axes
- GV does not align with the dominant component
- residual axes explain more than GV
- GV cannot preserve ordering across domains
- domain-specific rescue logic is required

## Scientific posture

If GV is not the whole structure, it may still be a dominant axis.

If GV is not dominant, it becomes a limited heuristic.

The test decides.
