## Core insight

Local compatibility is necessary but insufficient.

Random systems can fake local compatibility surprisingly well.

The deeper question is:

Can local persistence structures globally extend WITHOUT obstruction?

global continuation sections

obstructions to continuation

BUT
- global continuation secretly fails
