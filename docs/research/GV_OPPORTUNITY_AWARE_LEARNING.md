# GV Opportunity-Aware Learning

## Purpose

Build the monster.

The prior learning test showed:

GV learning preserved recoverability,
but became too cautious.

It learned from damage,
but not enough from missed opportunity.

## Core correction

A survivability learner must track two losses:

1. Damage loss
Loss of truth, constraint, correction, coherence.

2. Opportunity loss
Failure to explore when high-value basins were available.

## Strong GV evolution

GV is not:

- rigid safety
- reckless novelty
- naive recoverability maximization

GV is:

survivable exploration.

## Core hypothesis

Universal survivability requires learning the risk boundary between:

- destructive unrecoverability
and
- necessary kernel escape.

## New learning rule

If escape causes damage:
increase discipline and recovery.

If refusing escape misses basin growth:
increase future escape willingness.

If escape succeeds safely:
expand controlled risk capacity.

## Win condition

Opportunity-aware GV beats:

- strict viability
- fixed GV escape
- antifragile escape
- damage-only GV learning

on long-horizon survivability while preserving truth/constraint/coherence.
