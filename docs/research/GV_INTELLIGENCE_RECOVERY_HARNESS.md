# GV Intelligence Recovery Harness

## Purpose

Test the claim:

Intelligence needs recoverable continuity.

## Core idea

An intelligent system is not merely one that predicts.

An intelligent system must preserve enough continuity to recover from disturbance without losing:

- memory
- intent
- correction ability
- constraints
- truth-state
- global coherence

## Foundation

Persistent intelligence requires continuity-preserving structure.

## Failure modes

Intelligence degrades when it exhibits:

- memory fragmentation
- goal drift
- repeated uncorrected error
- constraint erosion
- local coherence with global collapse
- narrative protection of falsehood
- inability to preserve failed evidence as constraint

## GV intelligence test

A system is healthier when it can:

1. absorb perturbation
2. detect drift
3. correct course
4. preserve constraints
5. preserve truth-state
6. return to coherent behavior

## Scientific posture

This does not prove GV.

It tests whether intelligence continuity can be operationalized
as recoverability under perturbation.
