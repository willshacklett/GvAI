# Private Build encrypted workspace

The encrypted workspace broker is a trusted parent process. It exclusively owns
the adapter, `WorkspaceControlPlane`, authorization policy, worker and project
identity, granted authority, and AES-GCM key use. It starts each untrusted worker
with `posix_spawn`/exec semantics, an allowlisted environment, closed unrelated
file descriptors, and only JSON-lines stdin/stdout pipes. This avoids copying
the key-owning Python process with `fork`. Python attribute hiding or
name-mangling is not part of the security boundary.

Worker requests contain only an operation, relative path, and base64-encoded
content for writes. The broker rejects extra identity or authority fields and
attaches those values from trusted session state. Raw keys are never returned,
generated by the adapter, written to workspace storage, or included in audit
records. Production key material must be supplied by an external secret manager
or control-plane process.

Server-held authority and the control plane must approve each read or write.
Unknown operations, invalid paths, traversal, static symlinks, and control-plane
errors fail closed. Ciphertext is bound to its project and normalized relative
path with AES-GCM associated data. Audit records use stable SHA-256 references
instead of plaintext worker or project identifiers and omit paths, content,
ciphertext, keys, environment secrets, and raw exceptions.

This minimal broker assumes workers cannot directly access the trusted workspace
root through some separate filesystem mount or host API. Static symlinks are
rejected, but concurrent hostile filesystem mutation can race path validation;
this is not yet fully protected. It also does not provide network isolation,
resource limits, multi-process file locking, key rotation, deletion, directory
listing, quotas, rollback detection, or protection from a compromised trusted
broker. Deployments with hostile local users need OS-level filesystem isolation
and race-resistant directory-handle traversal in the broker process.
