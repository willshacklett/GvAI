# Humans Are Not Servers

## Core idea

Modern systems often treat humans as if they are infrastructure:

- always available
- always responsive
- always productive
- always connected
- always maintaining output

This is recoverability failure disguised as efficiency.

Humans are not servers.

Organic intelligence requires recovery cycles in order to sustain continuity.
